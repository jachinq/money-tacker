# 一期用持仓账户 + 只追加流水做申购/赎回，成本用平均法；观测表必留

用户会在同一产品上追加和部分赎回，银行页又不提供仓位。一期以 `(用户, 产品代码)` 为一本**持仓账户**，**流水只追加**（买入 / 赎回），剩余份额与剩余成本由流水还原；赎回扣成本用**平均成本法**。中行采集仍写 `nav_observation`：净值日不变时 `nav_snapshot` 不增行，没有观测就无法证明「当天拉过、仍挂零」。

**Status:** accepted

## Considered Options

- 一笔买入一行持仓、改错删除重建：实现短，无法表达部分赎回与已实现收益。
- 份额批次 FIFO：税务更细，个人理财追踪过重，一期不做。
- 不要观测表：库更小，挂零与「是否采过」只能猜。

## Consequences

- 总览按持仓账户（产品）聚合；详情看流水，不再以「一笔买入一行」为读写模型。
- 累计收益 = 未实现 + 已实现，赎回后赚钱仍留在产品维度。
- 分红再投、申赎费、业绩报酬仍不建模；用户按净额记账。
