# 产品刷新不新开采集，因此不写观测

持仓详情需要只更新一只产品的最新净值。观测必须属于一趟采集，而采集是整本代销目录的扫描，并且同时只能有一趟在执行。产品刷新若记成采集，要么占用这个名额，要么造出一趟没有扫目录的采集。两者都会让采集列表和「进行中」不再表示同一件事。

因此产品刷新只写净值记录和产品本身（名称、发行机构、在架），不产生观测。挂零仍只看净值记录里有没有该净值日，不靠观测证明「这一天拉过但官网没公布」。

**Status:** accepted

## Considered Options

- 记成一趟只含一页的采集并写观测：能证明拉过，但采集不再是全量扫描，也会和真正的采集抢进行中名额。
- 刷新前等待当前采集结束：观测好挂，但按钮会被整本目录拖住。

## Consequences

- 无法从观测回答「某次产品刷新当时页上的净值日是什么」。同一净值日再次出现时，净值记录会被覆盖，不另留历史版本。
- 全量采集结束时，仍可能把刷新刚标成在架的产品改回不在架，只要这次采集的目录里没有它。
